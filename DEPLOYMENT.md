# Telegram Web App - Music Intervals Training

## Описание

Это Telegram Mini App для тренировки музыкальных интервалов. Приложение реализовано как single-page application (SPA) в одном HTML файле и не требует backend-сервера.

## Возможности

### 4 типа упражнений:

1. **🎹 Арифметика нот** - Вычисление результата сложения/вычитания ноты и интервала
   - Пример: `D + 6 = ?` → ответ: `G#`

2. **📏 Вычисление интервалов** - Определение интервала в полутонах между двумя нотами
   - Пример: `C → E = ?` → ответ: `4`

3. **🎸 Разложение аккордов** - Определение нот, входящих в аккорд
   - Пример: `Am = ?` → ответ: `ACE`
   - Поддерживаемые типы: major, minor, 7, m7, sus2, sus4

4. **📖 Чтение табулатур** - Чтение последовательности нот с гитарной/укулеле табулатуры
   - Генерируются реалистичные табулатуры в одной тональности
   - Ноты расположены близко друг к другу на грифе

## Технические особенности

### Архитектура

Приложение следует трёхслойной архитектуре:

1. **Domain Layer** - Музыкальная теория
   - `Note` - представление ноты в хроматической гамме
   - `Interval` - интервалы в полутонах
   - `Chord` - аккорды с различными типами
   - `Key` - тональности (мажор/минор)
   - `Tablature` - генерация и отображение табулатур

2. **Training Layer** - Логика упражнений
   - `Exercise` - базовый класс упражнений
   - `NoteArithmeticExercise` - арифметика нот
   - `IntervalCalculationExercise` - вычисление интервалов
   - `ChordDecompositionExercise` - разложение аккордов
   - `TablatureReadingExercise` - чтение табулатур
   - `SessionStatistics` - статистика сессии
   - `TrainingSession` - управление сессией

3. **Application Layer** - UI и интеграция с Telegram
   - `MusicIntervalsApp` - главный класс приложения
   - Интеграция с Telegram Web App API
   - Управление экранами и навигацией

### Интеграция с Telegram

- Использует Telegram Web App API
- Адаптируется к теме Telegram (светлая/тёмная)
- Haptic Feedback при правильных/неправильных ответах
- BackButton для навигации
- Автоматическое расширение на весь экран

## Развёртывание

### Вариант 1: GitHub Pages (рекомендуется)

1. Создайте репозиторий на GitHub
2. Загрузите файл `index.html` в папку `docs/` или в корень репозитория
3. В настройках репозитория включите GitHub Pages
4. Получите URL вида: `https://username.github.io/repository/index.html`

### Вариант 2: Любой статический хостинг

Файл `index.html` можно разместить на любом статическом хостинге:
- Netlify
- Vercel
- Cloudflare Pages
- Firebase Hosting
- AWS S3 + CloudFront

### Вариант 3: Локальное тестирование

Для локального тестирования можно использовать простой HTTP-сервер:

```bash
# Python 3
python -m http.server 8000

# Node.js (npx)
npx http-server

# PHP
php -S localhost:8000
```

Затем откройте `http://localhost:8000/index.html` в браузере.

## Настройка Telegram бота

1. Создайте бота через [@BotFather](https://t.me/BotFather)
2. Получите токен бота
3. Настройте Web App через команду `/newapp` в BotFather
4. Укажите URL вашего развёрнутого приложения
5. Добавьте кнопку меню для запуска Web App

Пример команды для BotFather:
```
/newapp
@YourBotName
App Name: Music Intervals Training
Description: Train your music interval recognition skills
Photo: [загрузите иконку]
Web App URL: https://your-domain.com/index.html
```

## Формат ввода

### Ноты
- Натуральные: `C`, `D`, `E`, `F`, `G`, `A`, `B`
- С диезом: `C#`, `D#`, `F#`, `G#`, `A#`
- Можно использовать `.` вместо `#`: `C.` = `C#`
- Регистр не важен: `c#` = `C#`

### Последовательности нот
- Вводятся слитно: `ACE`, `C#EG#`
- Пробелы игнорируются: `A C E` = `ACE`

### Интервалы
- Целые числа от 0 до 11 (полутоны)

## Особенности UX

- **Автоматический переход**: После ответа следующий вопрос показывается автоматически через 1.5 секунды
- **Статистика в реальном времени**: Отображается количество правильных/неправильных ответов и точность
- **Визуальная обратная связь**: Зелёный цвет для правильных ответов, красный для неправильных
- **Тактильная обратная связь**: Вибрация при ответах (на поддерживаемых устройствах)
- **Адаптивный дизайн**: Работает на всех размерах экранов

## Технические требования

- Современный браузер с поддержкой ES6+
- JavaScript включён
- Telegram Web App API (автоматически доступен в Telegram)
