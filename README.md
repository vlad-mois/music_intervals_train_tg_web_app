# Telegram Web App - Music Intervals Training

Telegram Mini App для тренировки музыкальных интервалов, реализованное как single-page application в одном HTML файле.

## Файлы

- [`index.html`](index.html) - Основной файл приложения (полностью автономный)
- [`DEPLOYMENT.md`](DEPLOYMENT.md) - Подробная инструкция по развёртыванию и использованию

## Быстрый старт

### Локальное тестирование

```bash
# Запустите простой HTTP-сервер в этой директории
python -m http.server 8000

# Откройте в браузере
# http://localhost:8000/index.html
```

### Развёртывание на GitHub Pages

1. Загрузите `index.html` в репозиторий GitHub
2. Включите GitHub Pages в настройках репозитория
3. Получите URL: `https://username.github.io/repository/index.html`
4. Настройте Web App в [@BotFather](https://t.me/BotFather)

## Возможности

✅ **4 типа упражнений:**
- 🎹 Арифметика нот (D + 6 = ?)
- 📏 Вычисление интервалов (C → E = ?)
- 🎸 Разложение аккордов (Am = ?)
- 📖 Чтение табулатур

✅ **Полная интеграция с Telegram:**
- Адаптация к теме Telegram
- Haptic Feedback
- BackButton навигация
- Автоматическое расширение

✅ **Статистика в реальном времени:**
- Количество правильных/неправильных ответов
- Процент точности
- История сессии

✅ **Автоматический переход:**
- После ответа следующий вопрос показывается через 1.5 секунды

## Технические детали

- **Размер:** ~1100 строк кода в одном файле
- **Зависимости:** Только Telegram Web App API (загружается автоматически)
- **Архитектура:** Трёхслойная (Domain → Training → Application)
- **Технологии:** Vanilla JavaScript (ES6+), CSS3, HTML5

## Формат ввода

- **Ноты:** C, C#, D, D#, E, F, F#, G, G#, A, A#, B
- **Альтернатива:** Можно использовать `.` вместо `#` (C. = C#)
- **Регистр:** Не важен (c# = C#)
- **Последовательности:** Вводятся слитно (ACE, C#EG#)
